# 啓楷快跑！（嘉義輕軌）kai-run

純靜態網頁 3D 跑酷小遊戲（three.js）：Q 版張啓楷在灰色三線道上奔跑，路上會有 Q 版王美惠張開雙手擋路（有時還會側身走進你的車道），要閃過她和路障、立牌。輕軌軌道在車道之間蜿蜒，輕軌列車和你同方向、速度較慢，在列車旁邊切進軌道車道就能「上車」：+500 分，搭幾秒（無敵＋加速）後自動跳回路面。沿路收集薯條和雞肉飯。

- 玩法：← → 換車道、↑／空白鍵 跳、↓ 滑行、P 暫停；手機左右滑換道、上滑跳、下滑滑行、點一下跳。搭乘中按左右可提早跳車。
- 難度：起跑 11 m/s，前 300 公尺難度不增加，約 2500 公尺時到達最高 28 m/s。
- 線上玩：https://mmmarc2025.github.io/kai-run/
- 直接開 `index.html` 也能玩（`game.js` 是 esbuild 打包好的單一檔案）。修改 `src/main.js` 後重新打包：
  `npx esbuild src/main.js --bundle --format=iife --minify --target=es2019 --outfile=game.js`

非官方趣味小遊戲・角色為 Q 版創作造型。
